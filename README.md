# CAN API Project (Node.js + Express + PostgreSQL + Sequelize)

A complete REST API designed to manage the **Africa Cup of Nations (CAN) Tournament**.  
This project follows a clean **MVC architecture**, uses **Sequelize ORM**, and implements authentication, migrations, seeders, and full CRUD features.

---

## 🚀 Features

- JWT Authentication (Register / Login)
- Password hashing with bcrypt
- CRUD for:
  - Users
  - Teams
  - Players
  - Matches
- Organized MVC structure
- Sequelize ORM + Migrations + Seeders
- Environment variables with `.env`
- Centralized error handling
- Modular routers
- Database relations (One-to-Many, Many-to-Many)

---

## 🛠️ Technologies Used

| Technology | Purpose |
|-----------|----------|
| Node.js | Backend runtime |
| Express.js | Web framework |
| PostgreSQL | Main database |
| Sequelize ORM | Models, migrations & DB queries |
| JWT | Authentication |
| Bcrypt | Password hashing |
| Nodemon | Development hot reload |
| dotenv | Environment variables |
